# Hero background generator

`public/images/hero-editorial.jpg` is an original composition generated by these
two scripts, not a stock photograph. Kept in the repo so the image can be
re-rendered, recoloured or re-seeded without starting over.

    python3 gen.py     # traces topographic iso-lines -> contours.json
    python3 build.py   # composes hero.svg / hero.html
    # then render hero.html at 3840x2160 in a headless browser and save as JPEG

**gen.py** builds a value-noise field, adds a dominant radial term so the
iso-lines wrap the frame (pure noise clumped detail in one corner and left the
opposite edge bare), then extracts contours with marching squares and smooths
them into cubic beziers.

**build.py** layers the base gradient, light blooms, translucent strata, the
contours, sweeping "pathway" curves with faint nodes, a centre-attenuation mask,
vignette and film grain.

Two reasons this is vector-generated rather than photographic:

1. No licensing question of any kind. The practice asked whether the previous
   hero had been taken from another site; it was licensed Pexels stock, but this
   one is wholly theirs.
2. The quiet, low-contrast centre the hero panel needs is enforced by
   `#centerMask` rather than hoped for. Measured on the rendered page, the
   lightest pixel under the panel gives white text 10.54:1 (WCAG AA needs 4.5).

Palette matches `app/globals.css`: midnight `#0a1b30`, deep teal `#0d3f47`,
ocean `#1d5f78` / `#2b7c94`, ivory `#f2ece1`, warm gray `#a9a196`.
